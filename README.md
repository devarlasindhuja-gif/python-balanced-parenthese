# Python Balanced Parentheses

A beginner-friendly Python program that checks whether brackets in an expression are properly balanced using a Stack data structure.

## Data Structure Used

- Stack (LIFO - Last In, First Out)

## Supported Brackets

- ()
- []
- {}

## Example

Input:
{[()]}

Output:
Result: Balanced

Input:
{[(])}

Output:
Result: Not Balanced

## How to Run

Run the following command:

```bash
python balanced_parentheses.py

Features
Uses Stack concept
Checks (), [], and {}
Simple and beginner-friendly
